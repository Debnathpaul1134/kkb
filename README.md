# Birthday surprise website

A static, mobile-friendly birthday site. It needs no installation, build step, or server.

## Folder structure

```text
index.html          Main website
assets/images/      All personal photos
css/                Styling and animations
js/                 Interactions and Happy Birthday music
```

## Publish on GitHub Pages

1. Create a **new public GitHub repository**.
2. Upload the complete contents of this folder — keep the folders exactly as they are.
3. In GitHub, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main`, then select `/ (root)`, and save.
5. GitHub will show the live link after a minute or two. Send that link to her.

To personalise it, change the birthday message in `index.html`. The music button plays the traditional Happy Birthday melody after she taps it.
